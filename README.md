# Haven Theme

React + TypeScript storefront/showcase built with Vite and Tailwind.

## Run locally

```sh
npm install
npm run dev
```

The dev server runs on `http://localhost:8080`.

## Available scripts

```sh
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
